### Changed

- **The Edit/Write rule now says what it outranks.** Three delegated agents
  in one day edited tracked files with `sed -i` and heredocs, two of them for
  the single-token `(#NNN)` fill on a changelog fragment, because auto mode
  hands an agent a reminder that prescribes exactly that — and it arrives
  later in the context than `CLAUDE.md`, so it reads as the more recent
  instruction. The rule in `CLAUDE.md` and `.github/copilot-instructions.md`
  now states the precedence explicitly, and `.claude/guardrails.md` § "Delegated
  agents run on Opus by default" carries the two lines every agent brief has
  to spell out: repo files only through Edit/Write, and all `git` inside the
  agent's own worktree — a fourth agent's `git checkout -b` in the SHARED
  checkout moved a ref the author's own tree uses.
- **`/open-pr` knows what "ready to merge" means since the review ruleset
  changed.** `review_on_push` is `false` in both repos since 2026-09-03, so a
  fix push starts no Copilot run and the absence of a `copilot-*` check on the
  new head SHA is normal, not a reason to keep waiting. The merge-readiness
  conditions now read: non-Copilot checks completed and green (deduped by name,
  newest wins, so a superseded run is not read as red), a Copilot review that
  actually exists on the PR — the head check run only says whether a round is
  still running, since a run reaches `completed` with conclusion `cancelled`
  and delivers nothing — and zero unresolved threads. `mergeable=UNKNOWN` is
  GitHub still computing; a conflict (`mergeable=CONFLICTING`, in the richer
  `mergeStateStatus` enum `DIRTY`) gets no CI at all and is reported, not
  waited out.
- **A numeric UI rule is verified against the measured result.**
  `/verify-frontend` § 3b generalises its two a11y measurements into the rule
  they are instances of: a floor, a minimum size or a cap is checked on the
  page, never against the plan that was supposed to satisfy it. The case is
  the 14 px x-height floor of PR #535, whose planner sized lines from an
  average advance and left `/lesen/vergleichen` at 13.9 px — a rule broken by
  the code enforcing it, visible only in the browser.
- **Shortening a text that carries claims is now a checklist.** `/write-docs`
  gains the claim-by-claim diff duty: shortening drops qualifiers before it
  drops sentences, which is how the `/impressum` privacy section lost an
  overstated retention period, a condition on the objection right and part of
  a rights list inside an otherwise good edit. The author's own sentences stay
  verbatim, and site copy regenerates `app/prerender/` in the same push so
  crawlers stop being served the old claims.

### Added

- **Two operating patterns written down where they are needed.**
  `.claude/guardrails.md` gains a prod-touching section for the runbook the
  harness classifier refuses: one script in the scratchpad, one `! bash` line
  for the author with `rollback` as its argument, and a read-back from the
  session afterwards instead of trusting "done". `/verify-api` gains the
  contract-version duty for tools that write shared state — the payload
  carries the version, the SERVER answers `409` on a mismatch, as
  `tools.lesarten.sync` and `api/routers/lesarten.py` do since the versioned
  Lesart fold.
